\# Project Flashback Roadmap



Project Flashback is under active development. This roadmap describes areas of ongoing work and may change as development progresses.



\## Current Focus



\* Launcher stability and usability

\* Discord authentication and session handling

\* Server-side account systems

\* Locker entitlement management

\* Server-side rewards

\* Build and update infrastructure

\* Windows release improvements

\* Security and documentation



\## Near-Term Goals



\* Improve launcher reliability

\* Improve update and download handling

\* Expand account and profile functionality

\* Improve Locker management

\* Improve server-side reward systems

\* Improve public documentation

\* Prepare official releases for trusted code signing when available



\## Community



Bug reports, feature requests, documentation improvements, and code contributions are welcome.



See `CONTRIBUTING.md` for contribution guidelines and `SECURITY.md` for security reporting.
