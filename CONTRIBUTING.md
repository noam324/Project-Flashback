# Contributing to Project Flashback

Thank you for your interest in contributing to Project Flashback.

## Before Contributing

Please make sure that:

* Your changes are relevant to the project.
* You do not include passwords, tokens, API keys, OAuth secrets, or private keys.
* You do not commit personal information.
* Your changes do not intentionally bypass security protections.
* The project still builds successfully after your changes.

## Bug Reports

When reporting a bug, include:

* A clear description of the problem
* Steps to reproduce it
* Expected behavior
* Actual behavior
* Relevant logs or error messages
* Project version or commit when relevant

Do not include secrets or sensitive account information in bug reports.

## Feature Requests

Feature requests should explain:

* What the feature should do
* Why it would be useful
* Any relevant implementation considerations

## Pull Requests

Pull requests should:

1. Explain what was changed.
2. Explain why the change was needed.
3. Include relevant testing information.
4. Avoid unrelated changes when possible.
5. Avoid committing generated secrets or credentials.

## Security Issues

Please do not publicly disclose sensitive security vulnerabilities before they can be investigated.

See `SECURITY.md` for the project's security policy.
