# Privacy

## Overview

Project Flashback uses Discord OAuth for authentication and communicates with the Project Flashback backend for account-related functionality.

## Network Transfers

Project Flashback will not transfer information to other networked systems unless specifically requested by the user or the person installing or operating it.

The application may communicate with Discord and Project Flashback backend infrastructure when required for authentication and account functionality.

## Account Information

The backend may process information required for:

- Discord authentication
- Account and session management
- Player profiles
- Locker entitlements
- Server-side rewards
- Launcher and update functionality

## Secrets

Project Flashback does not intentionally commit OAuth client secrets, database credentials, session secrets, private keys, or other sensitive credentials to the public repository.

## Third-Party Services

Third-party services and components used by the project may have their own privacy policies and terms.
